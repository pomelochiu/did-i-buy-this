# did-i-buy-this 🛒

每次在購物社團看到好東西準備留言 `+1` 前，先問自己一句：**「我買過這個嗎？」**

這是一個純手機本地端運作的個人團購記帳與防呆工具（PWA），用來解決跨社團喊單容易失憶重複買、以及月底對帳算到眼花的痛點。

### 主要功能
- **喊單前防重複比對**：預設撈取近 3 個月相似紀錄與商品縮圖（支援自訂區間與拆字比對）。
- **極速登錄**：內建常用社團快選、自動分類、圖片壓縮與包色連存。
- **月結對帳**：依「月份＋社團」自動打包未付款項目，支援斷貨標記、運費與購物金折抵，一鍵付清歸檔。
- **純本地隱私**：所有資料與圖片僅存於個人手機（IndexedDB），支援一鍵匯出／匯入備份。
